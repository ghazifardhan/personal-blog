# Task Overview
Implement Phase 4 (Projects Portfolio) of the Personal Branding Website.

# Changes Made
- Expanded `content.config.ts` to include a new `projects` collection with a comprehensive schema (including `status`, `stack`, `github`, and `live` fields).
- Built `app/components/ProjectCard.vue` to display projects in a grid format, prominently featuring badges for the tech stack and status.
- Implemented `app/pages/projects/index.vue` to query the `projects` collection and render the portfolio grid.
- Implemented `app/pages/projects/[slug].vue` to display a single project case study. The layout is split into a metadata sidebar (tech stack, tags) and a main content area for the case study write-up.
- Created a sample project markdown file `content/projects/portfolio.md` to test the schemas and pages.

# Technical Decisions
- Enforced an `enum` on the `status` field in the zod schema to ensure consistent styling classes (`completed`, `in-progress`, `archived`) in the UI.
- Separated the layout of the blog post and project post: blog focuses on a reading experience (TOC, progress bar), while projects focus on structure, stack breakdown, and prominent external links.

# Verification
- The sample project successfully passes Nuxt Content parsing rules.
- The UI handles the absence of optional links (`github` or `live`) gracefully using `v-if` directives.
