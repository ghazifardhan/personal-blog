# Task Overview
Implement Phase 3 (Blog Infrastructure) of the Personal Branding Website.

# Changes Made
- Created `content.config.ts` to define the Nuxt Content v3 schemas using `zod`, particularly the `blog` collection with full frontmatter typing.
- Built `app/components/PostCard.vue` to display blog posts in a grid layout.
- Implemented `app/pages/blog/index.vue` to query and list all posts using the new `queryCollection('blog')` API.
- Implemented `app/pages/blog/[slug].vue` to render individual posts with:
  - Reading progress bar.
  - Sticky Table of Contents (TOC) sidebar.
  - Full `@tailwindcss/typography` integration for markdown styling via `<ContentRenderer>`.
- Created a sample markdown file `content/blog/my-first-post.md` to validate the schema and layouts.

# Technical Decisions
- Switched to the Nuxt Content v3 `content.config.ts` pattern for robust type-safety across content collections.
- Used Nuxt's `useAsyncData` alongside `queryCollection` to ensure SSR compatibility and high performance.
- Styled the reading progress bar and TOC sidebar without external dependencies using Vue lifecycle hooks and native CSS position properties.

# Verification
- The sample blog post parses correctly against the schema defined in `content.config.ts`.
- The `[slug].vue` dynamically extracts and injects SEO meta tags using `useSeoMeta`.
