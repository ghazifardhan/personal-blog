# Task Overview
Implement Phase 5 (Core Pages) of the Personal Branding Website.

# Changes Made
- Implemented `app/pages/index.vue` (Home Page) featuring:
  - A hero section with a gradient text effect on the headline.
  - A `Selected Projects` section that queries the `projects` collection for items marked as `featured: true` (limited to 3).
  - A `Latest Writing` section that queries the `blog` collection for items marked as `featured: true` (limited to 3).
- Implemented `app/pages/about.vue` (About Page) featuring:
  - A rich markdown-styled bio utilizing `@tailwindcss/typography`.
  - A highly visual tech stack grid utilizing `@nuxt/icon` to display technology icons.
  - A primary call to action (Contact).

# Technical Decisions
- Used `Promise.all` with `useAsyncData` on the Home Page to fetch both featured blogs and featured projects simultaneously, preventing waterfall requests during Server-Side Rendering (SSR).
- Re-used the `<ProjectCard>` and `<PostCard>` components to maintain design consistency across the application.

# Verification
- The Home page correctly integrates both `projects` and `blog` queries via the Nuxt Content v3 API.
