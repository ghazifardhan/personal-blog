# Task Overview: Create CI/CD for VPS Deployment

Created a GitHub Actions workflow and deployment configuration files (Docker and PM2) to enable automatic deployment of the Nuxt application to a VPS.

## Changes Made

- **New**: `.github/workflows/deploy.yml` - GitHub Actions workflow for SSH deployment.
- **New**: `Dockerfile` - Container definition for the Nuxt app.
- **New**: `docker-compose.yml` - Orchestration for Docker deployment.
- **New**: `ecosystem.config.cjs` - PM2 configuration for direct Node deployment.

## Technical Decisions

- **Hybrid approach**: Provided both Docker and PM2 configurations to give the user flexibility based on their VPS setup.
- **SSH Action**: Used `appleboy/ssh-action` in GitHub Actions for secure remote execution.
- **Pnpm**: Configured workflow and Dockerfile to use `pnpm` as it is the project's preferred package manager.

## Verification

- Verified the existence and content of all created files.
- The user needs to configure GitHub Repository Secrets (`SSH_HOST`, `SSH_USER`, `SSH_PRIVATE_KEY`) to activate the pipeline.
