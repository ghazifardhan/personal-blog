## The Challenge

Building a personal space on the web that feels both incredibly fast and uniquely mine. I wanted a platform that prioritizes typography, content readability, and an exceptional developer experience for writing articles.

## The Solution

I decided to utilize the latest **Nuxt ecosystem** tools to build a static-generated but highly dynamic site.

### Key Features

- **Markdown-driven**: All content is managed via markdown files, allowing me to write in my preferred editor.
- **Tailwind v4**: The entire design system is built on standard CSS variables integrated natively with Tailwind.
- **Dark Mode First**: Optimized for developers with an elegant dark theme out-of-the-box.
