# Kriya Labs EduTech Platform

Leading the mobile development at Kriya Lab, I architected and delivered an interactive learning experience that bridged the gap between instructors and students through technology.

## 🚀 Key Features

- **Interactive Learning**: Real-time quiz systems and video lesson streaming.
- **Optimized Performance**: Reduced app load times by **35%** through local database caching and API optimization.
- **Cross-Platform Excellence**: Shipped a single codebase to both iOS and Android with zero platform-specific UI discrepancies.
- **Robust Release Cycle**: Managed 20+ iterative version updates with automated crash reporting and user feedback integration.

## 🛠 Technical Implementation

- **Framework**: Flutter with BLoC/Cubit for predictable state management.
- **Backend**: Firebase for real-time notifications and Firestore for rapid data synchronization.
- **Analytics**: Deep integration with Google Analytics and Crashlytics to drive data-informed product decisions.
